# Sparse Activation Mixture Experts

This example demonstrates the concept of sparse activation in large AI models, specifically how a "Mixture of Experts" (MoE) architecture works. It simulates a large model with multiple specialized "experts" and a "router" that selectively activates only a subset of these experts based on the input, improving computational efficiency by not using all parameters simultaneously.

## Language

`python`

## How to Run

python main.py
